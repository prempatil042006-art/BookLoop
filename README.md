# BookLoop — Smart Second-Hand Engineering Book Price Prediction

## Run locally
1. Open this folder in VS Code.
2. Open Terminal in VS Code.
3. Install packages: `python -m pip install -r requirements.txt`
4. Start the app: `python -m streamlit run app.py`

## Features
- Price estimate using Random Forest Regression or Linear Regression
- Model evaluation with MAE, RMSE and R²
- K-Means clustering
- Dataset explorer and CSV download
- Branch and subject selection for multiple engineering study areas
- Responsive Streamlit interface

## Dataset note
The included dataset is generated demo data for educational testing, not verified market transactions. Predictions should be treated as estimates. For reliable market predictions, replace it with real book listings and actual sold prices.
